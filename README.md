# TrainBoardKit

전광판이나 열차 앞 표시를 카메라로 읽고 "이 열차 타도 돼?" 를 판정하는 엔진.
KORA(한국길찾기)와 일본길찾기가 함께 쓴다. 나라별 노선 데이터는 앱이 넘긴다.

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `TrainBoardJudge` | 전광판 한 줄로 판정: 방향이 맞는지, 열차 종류(급행·急行·快速)가 내 역에 서는지 |
| `TrainService` | 역을 건너뛰는 열차 종류 하나. 안내판에 적히는 말과 서는 역 |
| `BoardCamera` (iOS) | 뒤 카메라 + 기기 안 글자 인식. 글자를 전광판 줄로 묶어 넘긴다 |
| `BoardCameraPreview` (iOS) | 카메라 화면 |

## 판정 규칙

1. 전광판은 맨 윗줄이 다음 열차다. 위에서부터 무언가 말해 주는 첫 줄로 판정한다.
2. 내 방향 역 이름이 있으면 방향은 맞다. 그 줄의 열차 종류가 탄 역이나 내릴 역을 건너뛰면 `skipsStop`.
3. 열차 종류 말은 가장 긴 것을 고른다. `快速急行` 을 `急行` 으로 읽지 않는다.
4. 열차 종류 말이 없는 줄은 모든 역에 서는 열차로 본다.
